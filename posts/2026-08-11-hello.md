## Math

Inline math like $\text{softmax}(x)_i = e^{x_i} / \sum_j e^{x_j}$ works, and
so does display math:

$$
\text{Attention}(Q, K, V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
$$

MathJax renders both in the browser; nothing is required at build time.

## Code

Fenced blocks are syntax highlighted by Pygments. The language tag picks the
lexer.

```python
def attention(query, key, value):
    dk = query.size(-1)
    scores = torch.matmul(query, key.transpose(-2, -1)) / math.sqrt(dk)
    return scores.softmax(dim=-1) @ value
```

## Figures and footnotes

Images go in `static/images/` and are referenced from the site root. Wrap one
in a `figure` div to get the bordered, captioned treatment:

<div class='figure'>
    <img src='/images/example.png'>
    <div class='caption'>
        <span class='caption-label'>Figure 1.</span>
        The caption goes here.
    </div>
</div>

Footnotes are numbered automatically and collected at the bottom.[^note]
