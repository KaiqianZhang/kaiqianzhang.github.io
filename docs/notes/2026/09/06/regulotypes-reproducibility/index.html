Regulotypes: does the same map come back?

In real data there is no true R to compare against. What can be checked is whether the same organization of cells reappears when the loci, the donors, or the dataset used to estimate the map are changed.

Regulotype

The previous note asked whether the estimated map lands on the true one, in the only setting where the true one exists. Every statement there was a comparison against a matrix I had generated myself.

In real data there is no $R^{\mathrm{true}}$. A useful substitute is reproducibility: if the cellular organization reflects recurrent cis-regulatory biology, it should not depend on one lucky set of loci or donors.

Simulation lets us compare $\hat R$ with a known truth. Real data removes that reference.

This is not a fourth level of evidence stacked on the three the series has been using. It is what replaces Level 1 once the truth is gone — an internal check that asks the map to agree with itself under changes that should not have mattered, and it uses the same extension machinery the train-test design already needs.

What has to be stable

This changes the validation question. Instead of asking

$$ \hat R \stackrel{?}{\approx} R^{\mathrm{true}}, $$

we ask whether the same relationships among cells reappear when the information used to estimate the map changes.

The object to stabilize is still not an arbitrary orientation of $U$. It is the fitted cell-resolved effects and the geometry of the columns of $R$.

Almost everything below compares two distance matrices, so the distance is worth writing down before it is used. It is not the Euclidean distance between two columns of $R$. Two cells are compared over their whole cis-effect profiles, each pair's contribution divided by the scale of the molecular phenotype for that gene, and the whole thing averaged over pairs:

$$ d_R(i,i')^2 = \frac{1}{S} \sum_{s=1}^{S} \left( \frac{r_{si}-r_{si'}}{s_g} \right)^{\!2}. $$

The subscript on $s_g$ is the gene $g$ of pair $s$, not a second pair index. Two features of this definition carry weight in this note.

  • The average over pairs is what lets two reference sets of different size be compared at all. Without it, a set with twice as many pairs would return distances on a different scale, and none of the comparisons below would mean anything.
  • The per-gene scale $s_g$ decides what one unit of regulotype distance is, and it is not yet bound to a specific quantity. The choice interacts directly with everything that follows: if $s_g$ were estimated separately inside each training partition, $S^{(A)}$ and $S^{(B)}$ would be divided by different constants and their distance matrices would sit on different scales. A stability analysis run that way would be measuring the scaling and reporting it as biology. Until the binding is settled, the implementation refuses to compute Eq (12) rather than defaulting to a guess.

Change the reference cis regions

The cleanest reproducibility experiment keeps the cells fixed and changes the loci that define the map.

Split approximately independent reference regions into two sets,

$$ S^{(A)} \qquad\text{and}\qquad S^{(B)}. $$

Fit a regulotype map from $S^{(A)}$, and separately fit another map from $S^{(B)}$.

The two matrices have different rows, so their entries cannot be compared directly. But they describe the same cells.

For each fit, calculate its regulotype distance matrix,

$$ d_{R^{(A)}}(i,i') \qquad\text{and}\qquad d_{R^{(B)}}(i,i'). $$

Then compare the two geometries.

I would report:

  • correlation between the two distance matrices;
  • preservation of nearest regulotype neighbors;
  • stability of any low-dimensional visualization constructed from those distances.

This is a strong test of the core idea. If many independent cis loci reveal a recurrent cellular response structure, then changing the particular loci used to estimate it should not completely reorganize the cells.

It is also a test that can fail in two quite different ways, and the difference matters. The two locus sets can disagree because there is no shared response structure to find — no pair's effect actually varies with $u_i$, so each set is fitting its own noise. Or they can agree about the broad arrangement of cells while disagreeing about which cells are nearest neighbours, which is what happens when a real structure is estimated too coarsely. The first says the claim is wrong; the second says the claim is right but the resolution has been overstated. The lab below separates them.

Resample donors, not cells

Donors are the independent genetic units. A bootstrap that samples individual cells would therefore give a misleading impression of precision.

Instead, resample donors and keep all measurements from a selected donor together.

For bootstrap replicate $b$, fit

$$ \hat R^{(b)}. $$

The practical complication is that different bootstrap samples contain different cells. I would avoid comparing arbitrary factor coordinates across fits. Two alternatives are cleaner.

First, for cells that can be evaluated under multiple fits, compare selected cell-resolved cis-effect profiles and regulotype distances directly.

Second, use each bootstrap fit as a reference and project a fixed evaluation set of cells into it. Then every bootstrap produces a regulotype representation for the same evaluation cells, making distance and neighborhood stability directly comparable.

The second is the one that generalizes, because it reuses machinery the train-test design already needs: locating a cell that was not in the fit is exactly the new-column operation from the previous note.

Across bootstrap fits, summarize:

  • uncertainty in selected $r_{si}$;
  • uncertainty in $d_R(i,i')$;
  • stability of nearest neighbors;
  • stability of any discrete summaries of the continuous map.

The project already treats donor bootstrap fits as a source of uncertainty for $R$ and regulotype distances. This analysis turns that idea into a map-level reproducibility result.

If we draw groups, report assignment uncertainty

A continuous map may eventually be summarized into a few regions for visualization or downstream analysis.

If we do this, the group label should inherit uncertainty from the map.

For each bootstrap or alternative-reference fit, recluster or reassign cells using the same prespecified rule. For cell $i$, report an assignment probability such as

$$ \hat\pi_{ic} = \frac{1}{B} \sum_{b=1}^{B} \mathbf 1 \{\text{cell }i\text{ is assigned to region }c\text{ in fit }b\}. $$

A cell with assignment probability $0.98$ is qualitatively different from one that switches regions in half the fits.

This also prevents the discrete summary from becoming more certain than the continuous object that generated it.

Repeat the test across compatible datasets

The strongest reproducibility result would come from an independent dataset with compatible genotype and molecular measurements.

The datasets do not need to contain the same individual cells. The goal is to ask whether the same response organization appears.

A practical design is:

  1. learn the regulotype reference in dataset A;
  2. locate cells from dataset B using the projection mechanism;
  3. examine whether pair profiles, neighborhoods and known response continua reproduce;
  4. reverse the roles of A and B when sample size permits.

The exact cross-dataset comparison will depend on which genes, variants and cellular compartments overlap. I would therefore treat this as a later reproducibility analysis rather than the first one.

The essential rule is the same: the biological interpretation should not rest on a structure that disappears as soon as the reference loci or donors change.

Figure 2. A reproducibility ladder. Left to right, each rung changes more of the information the map was built from: the reference cis regions, then the donors, then the dataset. The three strips beneath every rung are the quantities compared, and they do not change as you climb — cell-resolved effects $r_{si}$, regulotype distances $d_R(i,i')$, and the stability of a cell’s nearest regulotype neighbours.

What should count as reproducible?

There is no single magic threshold.

I would look for agreement at several resolutions:

  • effect level: selected $r_{si}$ profiles remain similar;
  • geometry level: pairwise distances remain similar;
  • local level: cells retain similar regulotype neighbors;
  • summary level: discrete regions, if used, have high assignment stability;
  • biological level: later annotations of stable map regions recur across fits.

The first three are statistical reproducibility. The last one starts to connect the map to biology.

They also fail in that order. A map can be stable in its broad geometry and unstable in its neighborhoods, and in that case the honest report is the distance correlation with the neighborhood result beside it — not a picture of clusters.

Summary

Without a true $R$, validation has to rely on structures that survive changes in the data used to estimate them.

For the regulotype map, I would ask whether:

  • independent reference cis-region sets produce similar cell geometry;
  • donor-level bootstrap fits give narrow uncertainty for important effects and distances;
  • local neighborhoods remain stable;
  • discrete summaries have high assignment probabilities rather than brittle labels;
  • and compatible external datasets recover the same broad response organization.

These analyses answer:

$$ \boxed{\text{If I rebuild the map, does the same cellular organization come back?}} $$

Reproducibility makes the classification credible. It still does not prove that the classification is useful. For that, the map has to improve a task that matters outside the fitting data.
